# Global Agent - Backend Repository

## Overview

Global Agent is a gamified educational tool designed for middle and high school students to solve cases by investigating global current events. This backend repository supports the application functionality, ensuring a seamless experience for users.

## Technologies Used

- **JavaScript**
- **Node.js**
- **Express.js**
- **PostgreSQL**
- **React**
- **CSS**
- **API Integration**
- **Anthropic**
- **Firebase**
- **Google Cloud Translate**

## Features

- **Backend Development**: Engineered the backend using Node.js and Express to support application functionality.
- **Translation Services**: Enabled translation for English readability by using Google Cloud Translate, enhancing user accessibility.
- **AI Integration**: Integrated AI systems to generate dynamic multiple-choice questions and answers.
- **User Authentication**: Optimized user authentication by implementing Firebase login for secure access.
- **Team Collaboration**: Collaborated effectively with a team of five to ensure timely and successful product delivery.

## Getting Started

To run the backend server locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. Install the required dependencies:
   ```bash
   npm install
   ```

3. Set up your environment variables:
   - Create a `.env` file in the root directory and configure your database and API keys.

4. Start the server:
   ```bash
   npm start
   ```
